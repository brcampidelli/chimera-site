## Когда MCP блокирует запись

Чтение данных через MCP ранее приводило к загрязнению выполнения без объяснения причин сбоя записи. Сообщение об ошибке объединяло три различных сценария: отказ пользователя, настройки владельца и случаи, когда ни один человек не мог одобрить HTTP-запрос. Пользователи видели одинаковые сообщения об отказе для всех трех случаев, тратя время и бюджет на повторные попытки, которые заведомо не могли сработать. Теперь каждый случай получает конкретное объяснение — особенно важно для HTTP-контекстов, где сообщение четко указывает, что одобрение невозможно, и предлагает либо включить паузу для одобрения, либо избегать непроверенного контента.

## Тестирование, которое действительно тестирует

Кнопка тестирования MCP ранее проверяла подключение к серверу, но скрывала, могут ли агенты фактически использовать эти инструменты. Сервер мог пройти тест, но его инструменты оставались недоступными для агентов (например, когда загрузка серверов MCP при запуске была отключена). Теперь тест сообщает как о подключении, так и о фактической доступности, с отдельными сообщениями, объясняющими, как решить каждую потенциальную проблему.

## Проверка vs. Доставка

Проверка выполнения ранее показывала `verified: True`, не указывая, соответствуют ли текущие файлы тем, которые были проверены. Проверенное выполнение могло позже содержать совершенно другой контент (20/20 провалов тестов в одном наблюдаемом случае) без визуального указания. Теперь выполнения отслеживают `delivered_matches_verified` и отображают четкие значки, когда содержимое диска отличается от проверенного состояния.

## Обновлены модели по умолчанию

Набор моделей по умолчанию отстал от текущих предложений:
- Базовая модель изменена с `deepseek-chat-v3.1` (0.25/0.95) на `deepseek-v4-flash-0731` (0.065/0.18)
- Модель высшего уровня заменена с `deepseek-r1` на `z-ai/glm-5.3`
- Обновлены модели для судей и панелей до текущего поколения

Эти изменения отражают измеренные улучшения в цене, размере контекстного окна и сторонних тестах — а не непроверенные заявления о качестве. Обновление также удаляет предварительные модели из позиций по умолчанию, где пользователи их явно не выбирали.

## Другие исправления
- Ошибки установки навыков теперь правильно идентифицируют, какой хост отказал в запросе
- Разрешения на запись по абсолютному пути показывают четкие сравнения с глобальными шаблонами относительно рабочей области
- `.env.example` больше не предлагает устаревшие модели или некорректные цены

Обновите с помощью `pip install --upgrade chimera-agent` или ознакомьтесь с [Chimera Agent v0.49.3](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.49.3) для полной информации.
