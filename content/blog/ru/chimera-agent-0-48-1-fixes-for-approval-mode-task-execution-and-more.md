## Approval Mode теперь работает как задумано

Настройка `CHIMERA_APPROVAL_MODE=allow` теперь корректно применяется во всех интерфейсах, включая десктопное приложение и `chimera serve`. Ранее она работала только для `solve` и `crew`, что приводило к неожиданным отказам для большинства пользователей. Это исправление гарантирует, что опасные инструменты не блокируются при чтении ненадежного контента, что соответствует изначальному назначению настройки. Тесты показывают, что с подтверждением система блокирует 85.7% атак, разрешая всю легитимную работу — значительное улучшение по сравнению с прежним 50% уровнем ложных отказов.

## Унифицированный экран выполнения задач

Экран Work был переработан для устранения избыточности и улучшения удобства. Ранее пользователям приходилось выбирать между четырьмя формами для запуска задач, требующими одинаковых данных. Это создавало неудобства — попытка использовать другой метод означала повторный ввод. Теперь единый экран с четырьмя кнопками поддерживает все режимы выполнения, сокращая количество вкладок с пяти до четырех. Изменение также обеспечивает согласованность задач и проверок между режимами, тогда как попытки, роли и слоты остаются специфичными для каждого.

## Ключевые исправления и дополнения

- **Пустые переменные больше не крашат приложение:** Пустая переменная `CHIMERA_GUARD_CHAT` в файле `.env` ранее препятствовала запуску. Теперь пустые значения обрабатываются как не заданные.
- **Учет затрат для дорогих моделей:** Счетчик затрат теперь корректно отображает стоимость для всех моделей, включая `claude-opus-5` и `gpt-5.5`. Ранее из-за отсутствующего вызова функции их стоимость показывалась как неизвестная.
- **Фокусное кольцо для кнопок:** Компонент Button теперь использует общий стиль фокусного кольца, устраняя визуальное несоответствие.

## Новая функция: отложенная загрузка инструментов

Добавлена настройка `CHIMERA_DEFER_TOOLS` для сокращения расхода токенов путем отложенной загрузки схем инструментов до момента их использования. Тесты показывают снижение затрат на 26% на завершенную задачу, хотя влияние на успешность выполнения требует дальнейшего изучения. По умолчанию функция отключена из-за неоднозначных результатов.

## Что делать дальше

Обновитесь до Chimera Agent 0.48.1, чтобы воспользоваться этими исправлениями. Полный список изменений доступен в [Chimera Agent v0.48.1](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.48.1).
