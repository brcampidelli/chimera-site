## Модели для каждого проекта

До этого релиза смена модели для одного проекта меняла её для всех диалогов во всех проектах. Модель была единой глобальной настройкой, и если вам требовались разные модели для разных проектов, приходилось вручную переключаться туда-сюда. Это провоцировало ошибки и мешало держать проект на конкретной модели ради стабильности или экономии.

Теперь у каждого проекта может быть своя модель. Диалог в Code использует собственную закреплённую модель, если она задана, затем модель проекта, затем глобальную по умолчанию. В чеке шага отображается, какая модель была использована, так что вы можете убедиться в этом с первого взгляда. Смена модели для одного проекта больше не влияет на диалоги в другом. Это значит, что вы можете назначить проекту более дешёвую модель для экспериментов, а другому — более мощную для продакшена, не опасаясь перекрёстного влияния.

Когда агент предлагает сменить модель, он может лишь оставить вам карточку с указанием диалога или проекта, к которому это применится. Ничего не меняется, пока вы не одобрите. Это сохраняет контроль в ваших руках и не даёт агенту незаметно переключить модель посреди разговора.

## Модели Claude снова работают на экране Code

Если моделью по умолчанию была выбрана Anthropic, каждый шаг в Code падал на первом же действии с ошибкой о входной схеме инструмента. Схема инструмента question использовала конструкцию, которую API Anthropic отвергает. Это означало, что при использовании Claude как модели по умолчанию экран Code был полностью недоступен — каждый шаг завершался ошибкой, не сделав ничего полезного.

Теперь схема представляет собой простой объект, который API Anthropic принимает. Тест проверяет схему каждого инструмента, так что проблема не вернётся. Это исправление важно, потому что гарантирует работу всех поддерживаемых моделей на всех экранах, а не только тех, которые снисходительны к особенностям схем.

## Что делать сейчас

Обновитесь до версии 0.76.0 и задайте модель для конкретного проекта, если она вам нужна. Если вы избегали Claude на экране Code, попробуйте снова. Подробности — в [release notes][Chimera Agent v0.76.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.76.0).
