## Расширенная поддержка провайдеров с LiteLLM

Chimera Agent теперь полностью интегрирован с LiteLLM, что позволяет пользователям подключаться к любому провайдеру, поддерживаемому LiteLLM. Ранее распознавались только пять провайдеров, что оставляло пользователей с ключами для таких поставщиков, как Groq или Mistral, без возможности продолжить. Обновление гарантирует, что любой `<PROVIDER>_API_KEY` будет принят, при этом используется черный список для исключения провайдеров, не связанных с моделями, таких как ElevenLabs и Stability. Кроме того, `doctor` теперь отмечает нераспознанные имена провайдеров, помогая пользователям избежать опечаток, которые могут имитировать действительные провайдеры.

## Улучшенные элементы управления в интерфейсе

Три настройки, ранее доступные только через файлы `.env`, теперь доступны в интерфейсе: модель для эмбеддингов, базовый URL Ollama и пулы ключей. Настройка модели для эмбеддингов теперь напрямую связана с переключателем семантической памяти, что позволяет пользователям настраивать её без скрытых ошибок. Пулы ключей управляются через операции (добавление/удаление), а не прямое редактирование, что сохраняет безопасность, избегая отображения конфиденциальной информации.

## Исправления и улучшения

Прикрепление документов и диктовка сообщений теперь работают корректно, устраняя ошибку 422, вызванную некорректными заголовками Content-Type. Приложение также сохраняет вашу тему, рабочее пространство, список проектов и язык между запусками, исправляя проблему, при которой эти настройки терялись из-за изменений порта.

Чтобы изучить эти обновления, ознакомьтесь с [заметками о выпуске][Chimera Agent v0.43.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.43.0).
