## Задачи теперь видны

Ранее агенты хранили внутренний список задач (`RunState.tasks`), который никогда не отображался и не сохранялся. Долгие запуски могли терять прогресс при сжатии контекста. Теперь активная задача отображается во время выполнения, а завершённые задачи перечёркиваются. Список сохраняется после сжатия, поэтому агенты больше не забывают свой план в процессе работы.

## Запросы подтверждения следуют за вами

Три автоматизированные поверхности выполнения (включая cron-задачи) могли запрашивать подтверждения, но механизм был непрозрачным. При настройке с `CHIMERA_APPROVAL_WEBHOOK` агенты теперь направляют запросы подтверждения в указанный канал вместо тихого отказа, когда консоль недоступна. Система также явно сообщает о состоянии `unreachable`, если доставка невозможна.

## Улучшения управления и извлечения

Ядро доверия (`CHIMERA_GOVERNANCE`) ранее не имело контроля активации, несмотря на логирование событий безопасности. Теперь оно поставляется отключённым по умолчанию с видимым переключателем. Для извлечения данных `chimera find` теперь использует гибридный поиск (ключевые слова + векторы) по умолчанию после тестов, показавших его преимущество на 6.25 пунктов (p = 1.7e-04) по сравнению с поиском только по ключевым словам на корпусе проекта. Векторный поиск в одиночку показывает худшие результаты, что оправдывает комбинированный подход.

## Исправления обработки моделей

Агенты предполагали, что некаталогизированные модели имеют окно в 128k токенов, что приводило к сбоям для 31 модели (из 431 проиндексированных), которые на самом деле поддерживают ≤64k. Теперь система проверяет живой индекс для неизвестных моделей. Пять записей в каталоге были исправлены из-за завышенных размеров окон, а также устранена ошибка в ценообразовании (в 2.2 раза).

## Трассируемость и ограничения

Теперь трассировка записывает, какой бэкенд обслуживал каждый шаг, а не только какая модель отвечала. Это важно для сервисов вроде OpenRouter, где идентификаторы моделей представляют пулы с разбросом цен в 8.8 раза. В журнале изменений отозваны некоторые заявления о производительности, ошибочно сравнивавшие объединённые измерения.

Ключевые ограничения остаются: установщики не подписаны (хотя обновления подписаны), управление поставляется отключённым, а суммаризатор сжатия выключен по умолчанию, так как на практике не используется (0 срабатываний в 137 измеренных запусках). Отмена кооперативна — активные вызовы завершаются перед остановкой.

Подробности измерений и полный журнал изменений см. в [Chimera Agent v0.50.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.50.0). Для обновления: `pip install --upgrade chimera-agent`.
