## От консоли к редактору кода

Версия 0.44.0 кардинально меняет десктопное приложение Chimera Agent. То, что раньше было просто консолью для взаимодействия с агентами, теперь стало полноценной средой для редактирования кода. Это изменение отражает реальный workflow пользователей — не просто общение с ИИ, а совместную работу над кодом.

В этом релизе сразу семь ключевых функций. Редактор по адресу `#/edit` использует CodeMirror с вкладками, историей изменений для каждого файла и предупреждениями, когда агент пытается изменить несохранённый файл. Диагностика теперь работает через `ruff server`, так что ошибки совпадают с теми, что будут в CI. Редактор предлагает автодополнения от локальной модели — серый превью-текст можно принять Tab'ом или отклонить Escape.

## Практические улучшения

Поиск теперь работает по всему workspace, используя ripgrep где возможно. Видна загрузка системы (CPU, память, VRAM GPU), а также доступен semantic search по репозиторию с предустановленными бенчмарками. Командный раннер сохраняет историю между перезагрузками и корректно завершает процессы при остановке.

Самое важное — теперь можно делегировать задачи по коду внешним агентам вроде Claude Code или Gemini CLI. Они интегрируются через ACP и проходят ту же проверку с системой снапшотов/откатов, что и встроенные агенты. Приложение чётко указывает, когда внешние агенты работают в других security boundaries — они могут игнорировать файловые ограничения Chimera, но checkpoint/revert остаётся подстраховкой.

## Начало работы

Установка остаётся простой: нужен только ключ провайдера, остальные возможности подключаются опционально. Для диагностики установите `ruff`. Автодополнения требуют Ollama с конкретной моделью `qwen2.5-coder:1.5b-base` (именно base — instruct-модели не подойдут). Внешние агенты нуждаются в своих CLI-утилитах.

В релизе есть честные ограничения: неподписанные установщики вызовут предупреждения безопасности, у внешних агентов другие security boundaries, а semantic search пока не интегрирован в основной flow. Командный раннер — не полноценный терминал (каждая команда запускается в новом процессе, так что `cd` или `export` не сохранятся).

Подробности, включая два бага, найденных в нестандартных сценариях, — в [CHANGELOG][Chimera Agent v0.44.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.44.0). Чтобы попробовать, обновите Chimera Agent и откройте новый редактор по адресу `#/edit`.
