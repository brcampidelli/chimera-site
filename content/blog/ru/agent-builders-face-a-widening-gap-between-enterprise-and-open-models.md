Гонка за внедрение ИИ-агентов на рабочих местах создаёт две разные реальности. С одной стороны, коммерческие платформы быстро объединяют функциональность через поглощения [[1]](https://techcrunch.com/2026/09/14/superhuman-acquires-yc-backed-notetaker-fathom-as-productivity-platforms-push-for-agentic-work/), в то время как большинство организаций всё ещё не имеют инфраструктуры для разработки собственных агентских систем [[2]](https://iabrasilnoticias.com.br/empresas-brasileiras-esperam-retorno-de-investimento-de-15-com-ia-agentica-ate-2028/). Для разработчиков, работающих с открытыми моделями, это расхождение представляет как вызовы, так и возможности.

## Коммерческие решения оставляют мало места для кастомизации

Поглощение Fathom компанией Superhuman [[1]](https://techcrunch.com/2026/09/14/superhuman-acquires-yc-backed-notetaker-fathom-as-productivity-platforms-push-for-agentic-work/) наглядно демонстрирует, как платформы для повышения продуктивности интегрируют специализированные функции агентов в унифицированные коммерческие предложения. Эти готовые решения привлекают компании, ищущие быструю окупаемость инвестиций — бразильские компании ожидают 15% возврата от агентского ИИ к 2028 году [[2]](https://iabrasilnoticias.com.br/empresas-brasileiras-esperam-retorno-de-investimento-de-15-com-ia-agentica-ate-2028/) — но они предоставляют ограниченную гибкость для команд, которым нужны индивидуальные рабочие процессы. Те 3% компаний, которые чувствуют себя готовыми масштабировать ИИ-агентов [[2]](https://iabrasilnoticias.com.br/empresas-brasileiras-esperam-retorno-de-investimento-de-15-com-ia-agentica-ate-2028/), скорее всего, имеют выделенные инженерные ресурсы для разработки поверх этих готовых инструментов.

## Открытые модели демонстрируют неожиданную универсальность

Между тем, модели с открытыми весами продолжают демонстрировать возможности, выходящие за рамки их первоначального назначения. Недавно выпущенные агенты Iris [[3]](https://the-decoder.com/iris-mini-and-iris-pro-are-the-strongest-open-weight-search-agents-in-their-class/) показывают высокую производительность на задачах, для которых они не были специально обучены, включая использование инструментов общего назначения и офисную работу. Эта возникающая универсальность делает их ценными строительными блоками для разработчиков, создающих специализированных агентов, хотя они всё ещё требуют значительных усилий по внедрению по сравнению с коммерческими альтернативами.

Для разработчиков практический вывод очевиден: сосредоточьтесь на нишах, где коммерческие платформы не могут конкурировать. Открытые модели, такие как Iris [[3]](https://the-decoder.com/iris-mini-and-iris-pro-are-the-strongest-open-weight-search-agents-in-their-class/), лучше всего работают при решении проблем, слишком специфичных для универсальных платформ повышения продуктивности, особенно в областях, где существующие инструменты демонстрируют жёсткость. Ближайшие годы, вероятно, покажут доминирование коммерческих платформ в горизонтальных приложениях, в то время как открытые модели будут питать вертикальные инновации — разделение, которое играет на сильных сторонах каждого подхода.
