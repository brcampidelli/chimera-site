## Почему Docker-контейнеры падали при запуске

В Chimera Agent 0.45.0 появилась скрытая ошибка для headless-развертываний в Docker. Образ контейнера устанавливает `.[full]` без экстра `desktop`, что намеренно исключает FastAPI. Однако путь крон-заданий начал импортировать `chimera.api.usage`, вызывая преждевременную инициализацию API-модуля. Это потянуло FastAPI как косвенную зависимость через JSONL-ридер, приводя к циклам перезапуска контейнеров с `ModuleNotFoundError`.

Ошибка осталась незамеченной, потому что:
1. В средах разработки FastAPI обычно установлен
2. Ни один из 2,945 существующих тестов не имитировал чистую установку `.[full]`
3. Сбой проявлялся только в продакшен-развертываниях

## Ленивая загрузка для основных зависимостей

Исправление устраняет корневую причину, а не маскирует симптомы. Добавление `desktop` в образ сработало бы, но нарушило бы документацию экстры ("ядро CLI/шлюза никогда не требует этого") и увеличило бы размер образа без необходимости.

v0.45.1 изменяет `chimera/api/__init__.py`, чтобы:
- Разрешать реэкспорты лениво, а не сразу
- Изолировать зависимости FastAPI в веб-компонентах
- Сохранять четкие режимы сбоев, когда `desktop` действительно требуется

Пять конечных модулей (`usage`, `roles`, `sessions`, `posture` и `config_api`) больше не подтягивают веб-стек неявно при импорте CLI-операциями. Шлюз остается работоспособным с установленным только `.[full]`.

## Новая страховка

Теперь подпроцесс-тест проверяет, что импорты работают без FastAPI. Это позволило бы выявить проблему до релиза, так как:
1. Запускается в среде, где `fastapi` намеренно недоступен для импорта
2. Проверяет базовую функциональность перед другими тестами
3. Отражает реальные условия развертывания

End-to-end проверка подтверждает исправление: чистая установка `.[full]` теперь может запускать `serve --cron` без падений.

Обновитесь командой `pip install -U chimera-agent==0.45.1`. Для проверки развертывания протестируйте контейнер с `serve --cron` и убедитесь в сообщениях инициализации шлюза. [Chimera Agent v0.45.1](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.45.1) содержит полные технические детали изменений.
