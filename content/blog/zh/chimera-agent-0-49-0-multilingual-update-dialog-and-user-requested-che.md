## 多语言更新对话框与手动检查更新

现在，Chimera Agent 的更新对话框也能使用您的语言了。此前，无论应用的语言设置如何，更新对话框始终显示为英文。这一问题已得到修复，对话框现在会跟随操作系统的语言设置。这一变化确保未更改应用语言设置的用户会看到与系统语言一致的对话框，而自定义了语言设置的用户仍会看到英文对话框。

此外，系统托盘中新增了**检查更新**选项。这是首次提供手动检查更新的方式。自动检查仅在启动时运行一次，如果没有更新，则保持静默以避免打扰用户。然而，这种静默可能被误解为检查失败，导致用户不必要地重新启动应用。通过新的手动检查功能，用户可以确认应用是否为最新版本，或在检查失败时获得反馈。

## 翻译的故障对话框与未改动的诊断信息

更新对话框并不是应用中唯一被翻译的部分。两个后端故障对话框以及托盘中的退出选项现在也支持多语言。然而，翻译内容与未翻译内容之间有明确区分：

> **告诉您该做什么的内容会被翻译，而用于 bug 报告的内容则不会。**

例如，如果后端崩溃，错误信息会以您的语言显示，但路径、操作系统错误以及后端的 `stderr` 仍保持原始形式。这确保了用户仍能搜索并理解系统错误，而不会产生混淆。

## 未改变的部分

本次更新并未改变更新机制本身，该机制自 0.48.0 版本以来一直正常运行。自动检查仍会在每次启动时运行，安装过程仍由用户手动触发。应用运行期间不会进行周期性检查。

一个反直觉的细节仍然存在：**显示对话框的版本是已安装的版本，而非正在提供的版本**。这意味着，提示您更新到 0.49.0 版本的对话框是由当前运行的版本绘制的。从 0.49.0 版本开始，这一提示将以您的语言显示。
