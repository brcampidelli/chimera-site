## 从控制台到代码编辑器

Chimera Agent桌面应用在0.44.0版本实现了根本性变革。原先主要用于与代理交互的控制台，现已升级为成熟的代码编辑环境。这一转变反映了用户实际使用AI代理的方式——不仅是对话交流，更是协同编写代码。

本次更新同步带来七大核心功能。位于`#/edit`的编辑器采用CodeMirror技术，支持多标签页、单文件撤销历史记录，并在代理尝试修改你正在编辑的未保存文件时发出警告。诊断功能现由`ruff server`提供，确保所见警告与CI环境中的报错一致。编辑器还支持本地模型的行内补全，显示灰色预览文本，可通过Tab键接受或Esc键拒绝。

## 实用性改进

搜索功能现支持整个工作区，在可用环境下调用ripgrep引擎。可实时查看系统资源占用（CPU、内存、GPU显存），并通过预注册基准测试对代码库执行检索。命令运行器保留跨页面刷新的项目级历史记录，并在停止或关闭时正确终止进程树。

最具突破性的是，现在可将编码任务分派给Claude Code或Gemini CLI等外部代理。它们通过ACP协议集成，并遵循与原生操作相同的验证及快照/回滚流程。应用会明确标识外部代理在不同安全边界下的操作——它们可能绕过Chimera的文件写入保护，但检查点/回滚机制仍作为安全网存在。

## 入门指南

配置流程依然简单。仅需提供供应商密钥即可启动，可选功能均有明确标识。使用编辑器诊断需安装`ruff`。行内补全需要Ollama平台及特定的`qwen2.5-coder:1.5b-base`模型（注意base标签——instruct模型无法正常工作）。外部代理需安装对应CLI工具。

版本说明包含坦诚的注意事项：未签名安装包会触发安全警告；外部代理具有不同安全边界；检索功能尚未接入主代理流程。命令运行器并非完整终端——每个命令都在新进程中执行，因此`cd`或`export`等状态不会保留。
