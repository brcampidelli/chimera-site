## 更新程序现在持续工作

在之前的版本中，更新程序仅在启动时检查一次新版本。这对于像 Chimera Agent 这样设计为长时间运行的应用程序来说，是一个明显的疏忽。因此，用户常常错过更新，除非他们手动检查或重启应用程序。这个问题在 0.49.1 版本发布时尤为明显：应用程序没有通知用户更新，迫使他们手动从网站下载安装程序。

**在 0.49.2 版本中，更新程序现在每六小时检查一次新版本**，只要应用程序在运行。这一变化确保用户能及时收到更新通知，而无需频繁重启。此外，更新程序通过记住在进程期间被拒绝的更新，避免了不必要的打扰。如果有新版本可用，它会再次提示用户，确保手动更新请求始终得到处理。

## 安装程序修复生效

0.49.1 版本引入了一个修复，解决了安装程序遗留旧版本文件的问题。具体来说，`_internal` 目录可能包含多个 `chimera_agent-*.dist-info` 目录，导致应用程序报告错误的版本并反复提供更新。然而，这个修复仅适用于发布时附带的安装程序，而不是用于就地更新的安装程序。

**0.49.2 是第一个使用修复后安装程序进行就地更新的版本。** 如果你更新到 0.49.1 并遇到版本报告错误的问题，这个版本将解决该问题。安装程序现在能正确删除旧文件，确保版本报告准确，并避免冗余的更新提示。

## 其他改进

如果你跳过了 0.49.1 版本，以下是该版本引入的其他值得注意的改进：

- **新版本在附加清单之前不会发布为“最新”版本。** 之前，在构建过程中，更新程序端点会返回 404 错误，由于错误信息被抑制以避免打扰用户，更新会静默失败。
- **失败对话框和托盘通知现已本地化**，而技术诊断信息仍保持英文，以确保易于搜索。
- **首次运行向导的成本模式在本地化屏幕上不再显示为未翻译的英文单词**。

有关完整详情，请参阅[发布说明][Chimera Agent v0.49.2](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.49.2)。

要享受这些修复，请立即更新到 Chimera Agent 0.49.2。
