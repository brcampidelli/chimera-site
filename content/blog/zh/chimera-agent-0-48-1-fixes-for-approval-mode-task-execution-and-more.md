## 审批模式现已按预期工作

`CHIMERA_APPROVAL_MODE=allow` 设置现在能在所有界面正常生效，包括桌面应用和 `chimera serve`。此前该设置仅对 `solve` 和 `crew` 命令有效，导致多数用户遭遇意外拒绝。此修复确保在读取不受信任内容时，危险工具不再被错误拦截，符合该设置的原始设计意图。基准测试显示，在审批机制启用时，系统能拦截 85.7% 的攻击行为，同时允许所有正常操作，较之前对合法任务 50% 的误拒率有显著提升。

## 统一的任务执行界面

工作界面现已简化冗余设计并提升可用性。此前用户需在四种任务执行表单中选择，尽管它们需要完全相同的输入内容。这种设计导致效率低下——尝试不同执行方式意味着重复输入任务内容。新版采用单一界面搭配四个功能按钮，将标签页数量从五个缩减至四个。该变更还确保任务与检查在不同模式下保持一致性，而尝试次数、角色和工作槽位仍保持模式专属特性。

## 关键修复与新增功能

- **空变量不再导致崩溃**：此前 `.env` 文件中空的 `CHIMERA_GUARD_CHAT` 变量会阻止应用启动，现已修复为将空值视为未设置状态。
- **昂贵模型成本计量**：成本计量器现在能正确显示所有模型（包括 `claude-opus-5` 和 `gpt-5.5` 等昂贵模型）的费用。此前因缺少函数调用，这些模型会显示未知成本。
- **按钮聚焦环统一**：Button 组件现在正确采用共享聚焦环样式，修复了视觉不一致问题。

## 新功能：延迟工具加载

新增 `CHIMERA_DEFER_TOOLS` 设置，通过延迟加载工具模式来减少 token 消耗。基准测试显示每项完成任务的成本降低 26%，但对任务完成率的影响尚无定论。由于效果不稳定，该功能默认关闭。
