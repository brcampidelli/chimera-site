## 更新流程改进

Chimera Agent 0.49.0 的更新机制存在一个严重问题：由于之前安装的残留文件，后端进程错误地报告了版本号。具体来说，PyInstaller 包保留了旧版本和新版本的 `dist-info` 目录，导致 `importlib.metadata` 返回了错误的版本号。这使得应用持续提示更新到它已经安装的版本。现在，安装程序会在写入新版本之前移除旧包，确保只报告正确的版本号。需要注意的是，此修复适用于 0.49.1 附带的安装程序，而不是安装它的那个程序。如果你是从 0.49.0 更新，在下一次更新之前，你可能仍会看到一个过时的 `dist-info`。

## 自动更新的可靠性

自动更新机制中还发现了另一个问题。每次发布后大约二十五分钟内，更新程序会失败，因为 `latest.json` 端点返回了 404 错误。这是因为在所有平台构建完成之前，发布就被标记为最新版本。现在，发布会被暂时标记为 `--latest=false`，只有在清单附加后才提升为最新版本。这确保了端点始终解析到有效的发布，提高了可靠性，并防止提供损坏的发布。

## UI 一致性与清晰度

之前的“有新版本可用”面板提出了一个它无法回答的问题：*“有新版本可用。要更新吗？”* 然而，面板只提供了查看发布或关闭通知的选项，并没有实际的更新功能。现在，面板仅简单地通知有新版本可用，并引导用户使用托盘中的**检查更新**选项。这一变化消除了混淆，使 UI 与其实际功能保持一致。

## 翻译修复

首次运行向导中存在一个微小但明显的翻译问题：成本模式下拉菜单显示了原始值（`auto / cheap / balanced / premium`），而不是它们的翻译版本。虽然标签存在且已被翻译，但在此上下文中未被使用。这一不一致性已得到修复，确保下拉菜单现在显示正确的翻译标签，与设置屏幕保持一致。

如需完整详情，请参阅[发布说明][Chimera Agent v0.49.1](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.49.1)。要更新，请运行 `chimera-desktop --update` 或从官方网站下载最新版本。
