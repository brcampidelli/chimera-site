## 何が変わるのか

これまで、サンドボックス外に触れるツール呼び出しは全て承認カードを生成していた。毎回クリックする必要があった。それが設計上の契約だ。エージェントは停止し、あなたが判断し、処理を続行する。スクリプトのイテレーション中に、同じ安全なコマンドを12回連続で実行する必要がある場合でも、この契約は守られていた。この摩擦はバグではなく、意図された設計だ。しかし、それが迅速なイテレーションを不必要に遅くしていた。

バージョン0.75.0では、Code Composer に「権限を無視」というスイッチを追加する。これをオンにすると、通常は承認カードを生成するツール呼び出しをエージェントが自動承認する。あなたに代わって下した判断は全て記録される。このスイッチは一つの会話にのみ適用される。アプリの再起動後には保持されない。また、ローカルデータを外部に送信するものには一切触れない。プッシュ、公開、支払い、あなたの名前で送信されるメッセージ、シークレットへのアクセス、そしてマシン外にデータを転送する操作は、これまで通り停止し、確認を求める。境界は明確だ。エージェントは境界の内側で高速に動作できるが、あなたなしに境界を越えることはできない。

これはグローバル設定ではない。設定ファイルのトグルでもない。画面上のボタンであり、押せるのはあなただけだ。この設計は、オーバーライドを作業のそばに置く。あなたは会話を見て、エージェントが何をしているかを把握し、このセッションでは繰り返しの承認はノイズだと判断する。アプリが再起動すれば、ノイズは戻ってくる。あなたは再び、意図的にオプトインする。

## タイムアウトの挙動が変わった理由

Code 画面には、あなたの回答に5分間の期限があった。その時間内に承認カードに応答しない場合、エージェントは呼び出しを拒否し、会話は停止した。未応答のカードは放置されたセッションを意味する、という前提があった。しかし、この前提は一般的なワークフローで破綻していた。あなたがエージェントに何かを依頼し、別のウィンドウに切り替えてドキュメントを確認したり仮説を検証したりして、6分後に戻ってくると、会話は死んでいる。タイムアウトは集中を罰していたのだ。

Code 画面は今後、あなたの回答を無期限に待つ。あなたが戻るまで、エージェントは一時停止したままだ。5分間の制限は、それが理にかなう場所、つまり誰も監視していない自動化には引き続き適用される。そちらにはガードレールが残る。しかし、あなたがその場にいるなら、たとえ離席しても、会話が期限切れになることはもうない。

## このスイッチがしないこと

「権限を無視」スイッチは sudo フラグではない。権限を昇格させない。エージェントが既に要求できたもの以外へのアクセスを許可しない。単に、各リクエストを手動で承認する要件を取り除くだけだ。エージェントは自動承認した全ての呼び出しをログに記録する。後から何が起こったかを確認できる。セッションを監査する必要がある場合、その記録はそこにある。

明示的な承認が依然として必要なカテゴリは、マシン外にデータを移動したりリソースを消費したりするものだ。リモートへのプッシュ、公開操作、支払いアクション、あなたのアイデンティティを伴うメッセージ、そしてシークレットやローカルデータを読み取ったり外部に送信したりするもの全てが該当する。スイッチはこれらのカテゴリを無条件に尊重する。オーバーライドをオーバーライドする第二のスイッチは存在しない。

## 次にすべきこと

0.75.0 にアップデートしてほしい。ツール呼び出しが繰り返し発生しそうな Code Composer セッションを開く。画面上の「権限を無視」スイッチを探す。承認カードがノイズになったらオンにする。ガードレールが必要に戻ったらオフにする。アプリを再起動すればリセットされる。変更点の全リストは[リリースノート][Chimera Agent v0.75.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.75.0)で読める。
