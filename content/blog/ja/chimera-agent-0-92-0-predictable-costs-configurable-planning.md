## 実際の支払額と一致するコストレシート

0.92.0 より前は、`serve` 外でのコスト追跡は静的なカタログに依存しており、実際のプロバイダ料金と乖離していました。実行時に表示されるコストは一見妥当に見えても誤っており、予算計算を狂わせるほどの差が生じることもありました。この不一致は、カタログが認識できない正確なモデルスラッグを使用した場合に特に顕著で、汎用的なレートにフォールバックするか、単に役に立たない値が表示されていました。

今回のリリースでは、`serve` を経由しない実行に対し、OpenRouter の公開価格インデックスを参照するように切り替えました。正確なモデルスラッグは、ファミリー平均にまとめられることなく、個別のレートに解決されるようになりました。呼び出しが strict（プロバイダとモデルが実行開始時に固定される）である場合、レシートには受け入れられた見積もりが保持されるため、表示される数字は実際に承認された金額そのものになります。`gpt-oss-20b` のカタログエントリも現在の価格に合わせて更新されました。

実用上の効果として、バッチ実行のレシートを受け取り、想定ボリュームを掛け合わせるだけで、信頼できる数字が得られるようになります。プロバイダのダッシュボードと手動で突き合わせる必要はもうありません。

## プランナーはあなたが制御するスイッチに

これまで、プランナーは常にオンでした。特定のカンバンレーンや API 呼び出し、ワークフローの解決ステップに対してオフにすることはできませんでした。つまり、タスクが些細なものであったり、指示がすでに十分明示的でプランニングが不要な場合でも、すべてのタスクがプランニングパスのレイテンシとトークンコストを支払っていたのです。

バージョン 0.92.0 では、`use_planner` を設定フラグとして公開しています。レーン、実行、または解決ステップで `false` に設定すると、エージェントはプランニングフェーズを完全にスキップします。デフォルトは `true` のままなので、明示的に設定しない限り既存のワークフローの動作は変わりません。このフラグは、カンバン設定、API、ワークフロー定義の3つのインターフェースすべてで利用可能なため、選択的に適用できます。単純な分類を処理するレーンはプランニングをスキップし、隣接する多段階の調査を行うレーンはプランニングを維持する、といった使い分けが可能です。

なぜプランニングを賢くしようとしないのか？それは、推測を誤るコストが、スイッチを提供するコストよりも高いからです。プランニングが必要かどうかを判断しようとするヒューリスティックは、時に誤った判断を下し、そのデバッグは、自分で制御できる boolean を切り替えるよりもはるかに困難です。

## 実際に見つけられるデスクトップ設定

デスクトップアプリの設定検索は、これまでロール別モデルのルーティングテーブルを見逃していました。「routing」や「role」と入力しても結果が表示されず、実際には設定パネルにそのテーブルが存在しているにもかかわらず、見つけられなかったのです。これは修正され、ルーティングテーブルがインデックス化され、検索結果に表示されるようになりました。

今回のリリースでは、2つのローカライゼーション修正も同梱されています。ルーティングテーブルとレシートのコピーがブラジルポルトガル語で正しく表示されるようになりました。以前は一部のラベルが英語にフォールバックしていました。新しい会話や応答のみのターンでも、より明確なステータスメッセージが表示されるようになり、モデルが考えているのか、接続が切れたのか、スピナーを見つめながら悩むことはなくなりました。

## 実験的機能の現状

いくつかの実験的機能が、デフォルトを変更することなくアップデートされました。メモリ抽出ベンチマークは決定的な結果が得られなかったため、6,000文字の上限とグローバルモデルは維持されています。新しいパスをテストしたい場合は、明示的な抽出モデルと決定論的プレフィルターにオプトインできます。cron モデルティアの実験では、8つの合成ジョブのうち7つで完全な正しさを示しましたが、合成ジョブは本番ジョブではないため、デフォルトは変更されていません。リーンなデザインリファインメントとプロンプト比例性の実験も、デフォルトではオフのままです。

デスクトップインストーラーは依然として未署名であり、初回起動時にプロンプトが表示される可能性があります。アプリはアップデーターバンドルの署名を検証します。

`pip install chimera-agent --upgrade` でアップグレードし、必要に応じて `use_planner` を設定してください。全変更履歴は [Chimera Agent v0.92.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.92.0) にあります。
