## 承認機能が壊れていた原因と、競合が起きなくなった理由

今回のリリース以前は、デザインを承認しようとすると「別の Chimera プロセスがこの質問を要求しました」という不可解なメッセージで失敗することがあった。この失敗は別プロセスとは一切関係ない。デザイン承認は自身の会話内で質問として応答され、その回答は承認ウィンドウ、ステータスバー、Governance リストに表示される。回答できるのはオーナーの画面だけだ。問題は、二つの回答が同時に到着すると衝突し、システム側に一つだけを記録して先に進む手段がなかったことにある。エラーは単なるノイズだったが、承認をブロックし、ユーザーに明確な復旧手段を残さなかった。

バージョン 0.79.1 はこれを正しく処理する。二つの回答が同時に承認へ届いた場合、厳密に一つだけが記録される。競合は拒否されるのではなく、解決される。承認は完了し、デザインは先に進み、ユーザーは三つの UI すべてで一貫した状態を確認できる。デザイン出力を生成し、それを人間の承認ステップに通すエージェントを構築する人なら誰でも、並行性とは本来無関係だった断続的なクラッシュなしに、Governance フローを信頼できるようになる。

## 空白のテキストではないデザイン提案

Chimera Design にはもっと深刻な問題があった。最初の提案が実質的に使い物にならなかったのだ。モデルは不正な形式の操作を返し、システムはモデルが修復できない生のエラーを表示し、会話は停止していた。操作が構造的に有効だったとしても、提案自体はプレーンテキストで、タイポグラフィも背景も図形もなかった。つまり、Design との最初のやり取りは、視覚的な出力を求めるプロンプトに対して、視覚的なものが何も返ってこない状態だった。

修正は四つのパートからなる。不正な形式の操作は、モデルが修正可能な引数エラーとして返されるようになり、会話が停止する代わりに自己修正される。各操作は期待される形状を示すようになり、モデルが狙うべきターゲットを得る。一つのターンに詰め込みすぎて提案が途切れた場合、システムはその切り捨てを検出し、より少ない操作数で再要求する。最後に、最初の提案はデフォルトでタイポグラフィ、背景、図形を要求するようになり、最初のターンから出力が視覚的に始まる。結果として、手動のリトライループなしで使える最初の提案が得られる。

## 起動するコネクタと、コンテキストを圧迫しないファイル

外部ツールを接続するすべての人にとって重要な、二つのインフラ修正がある。一つ目は、`.cmd` ランチャー経由でコネクタを実行する Windows ユーザー（`npx` 経由の Supabase が一般的なケース）が、コネクタのコマンドに含まれる URL 内の `&` で暗黙の破損に遭遇していた問題だ。ランチャーがその文字を解釈し、コマンドが分割され、コネクタは起動しなかった。Chimera は安全に渡せない引数を拒否し、その理由を伝えるようになったため、失敗が明示的かつ修正可能になる。また、アプリは MCP サーバーの接続を待ってから開くことをやめた。以前は、コネクタがタイムアウトする間、最大2分間 UI が「Failed to fetch」で止まることがあった。サービスは即座に開き、接続はバックグラウンドで解決される。

二つ目は、音声や画像をインラインで返すコネクタ（例えば VoiceStudio のナレーション）が、base64 をモデルのコンテキストに直接ダンプしていた問題だ。モデルはエンコードされた blob をテキストとして読まなければならず、コンテキストウィンドウを満たしてターンを停止させていた。これらのファイルはプロジェクトの `mcp-output/` フォルダに保存され、コミットから除外され、会話はそれらを再生可能または表示可能なアーティファクトとして参照する。モデルが生のバイト列を見ることはなくなり、コンテキストを使い果たすことなくターンが完了する。

## 再起動後も生き残る権限状態

「Ignore permissions」スイッチはプロジェクトレベルで保持され、再起動後も持続するようになった。プロジェクトレベルのスイッチは、新規のものを含むすべての会話をカバーし、各会話は依然として独立したトグルを保持する。プロジェクトスイッチをオンにすると、すでに権限を待っているカードが即座に解放される。再起動後は、スイッチがオンだった保存済みのプロジェクトと会話をバナーが一覧表示する。ワンクリックで再有効化を確認し、残りは破棄される。スイッチをオンにできるのはデスクトップ画面のみで、オフにするといつでも全適用される。安全境界は一方向だ。

## 今やるべきこと

`pip install chimera-agent==0.79.1` でアップグレードしてほしい。Design を使うなら、新しい提案を開始し、最初の応答に視覚的構造が含まれていることを確認してほしい。Windows で Supabase や `npx` ベースのコネクタを使っているなら、手動で引数をエスケープしなくてもコネクタが起動することを検証してほしい。全ノートは [Chimera Agent v0.79.1](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.79.1) にある。
