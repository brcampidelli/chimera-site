## 更新フローの修正

Chimera Agent 0.49.1で対応した最も重要な問題の1つは、更新メカニズムに関するものです。以前は、インプレース更新後に、バックエンドプロセスが誤って古いバージョンを報告していました。これは、前のインストールから残っていた`dist-info`ファイルが原因で発生していました。PyInstallerバンドルが古いバージョンと新しいバージョンの両方のファイルを保持していたため、`importlib.metadata`が最初に検出したバージョンを返していたのです。その結果、アプリは既に実行中のバージョンへの更新を繰り返し提案し、混乱や不要な更新プロンプトを引き起こしていました。

この問題を解決するため、インストーラーは新しいバンドルを書き込む前に古いバンドルを削除するようになり、正しいバージョンのみが認識されるようになりました。ただし、この修正は0.49.1で出荷されたインストーラーに適用されるもので、0.49.1をインストールするために使用されたインストーラーには適用されません。0.49.0から更新するユーザーは、次の更新までこの問題に遭遇する可能性があります。手動での修正方法としては、古い`dist-info`ファイルを削除し、アプリを再起動します。

もう1つの更新関連の問題は、自動更新機能に関するものでした。リリース後約25分間、アップデータは失敗していました。これは、ビルドがまだ進行中である間、`releases/latest/download/latest.json`エンドポイントが404エラーを返していたためです。この問題は、アップデータがエラーを黙って飲み込んでいたため気づかれませんでした。現在では、すべてのビルドが完了するまで`--latest=false`でリリースが保留され、エンドポイントが常に有効なリリースを返すようになっています。

## UIの一貫性と翻訳の修正

「新しいバージョンが利用可能」パネルは、以前は答えられない質問をしていました。パネルの見出しには「新しいバージョンが利用可能です。更新しますか？」と表示されていましたが、リリースを表示するかパネルを閉じるかのボタンしか提供されていませんでした。このパネルはWebView内にあり、RustアップデータへのIPCがないため、更新を開始できなかったのです。現在では、パネルは単に新しいバージョンの利用可能性を伝え、トレイの「更新を確認」オプションを利用するようユーザーに案内します。

さらに、初回起動ウィザードのコストモードドロップダウンに翻訳漏れがあり、翻訳されたラベルではなく生の値（`auto / cheap / balanced / premium`）が表示されていました。この不整合は修正され、ウィザードは既に翻訳ラベルを使用していた設定画面と一致するようになりました。なお、値自体はサーバーが期待する入力に合わせて英語のままです。
