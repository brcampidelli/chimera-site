## 更新プロセスの改善

Chimera Agent 0.49.0の更新メカニズムには重大な欠陥がありました。以前のインストールから残ったファイルにより、バックエンドプロセスが誤ったバージョンを報告していました。具体的には、PyInstallerバンドルに古いバージョンと新しいバージョンの両方の`dist-info`ディレクトリが残っていたため、`importlib.metadata`が間違ったバージョンを返していました。これにより、アプリは既にインストールされているバージョンへの更新を繰り返し提案していました。インストーラーは現在、新しいバンドルを書き込む前に古いバンドルを削除するため、正しいバージョンのみが報告されます。この修正は0.49.1で出荷されるインストーラーに適用されますが、0.49.0から更新する場合、次の更新まで古い`dist-info`が残っている可能性があることに注意してください。

## 自動更新の信頼性向上

自動更新メカニズムにも問題が見つかりました。リリース後約25分間、`latest.json`エンドポイントが404エラーを返すため、アップデータが失敗していました。これは、すべてのプラットフォームビルドが完了する前にリリースが最新としてマークされていたためです。現在、リリースは`--latest=false`で保留され、マニフェストが添付された後にのみ最新として公開されます。これにより、エンドポイントは常に有効なリリースを返すようになり、信頼性が向上し、問題のあるリリースが提供されるのを防ぎます。

## UIの一貫性と明確化

以前の「新しいバージョンが利用可能」パネルは、答えられない質問をしていました：*「新しいバージョンが利用可能です。更新しますか？」*しかし、パネルにはリリースを表示するか通知を閉じるかのオプションしかなく、実際の更新機能はありませんでした。パネルは現在、新しいバージョンが利用可能であることを単に通知し、ユーザーをトレイの**更新を確認**オプションに誘導します。この変更により混乱が解消され、UIの実際の機能と一致するようになりました。

## 翻訳の修正

初回実行ウィザードには、小さなが目立つ翻訳の問題がありました。コストモードのドロップダウンに翻訳されていない生の値（`auto / cheap / balanced / premium`）が表示されていました。ラベルは存在し翻訳されていましたが、このコンテキストでは使用されていませんでした。この不整合は修正され、ドロップダウンには設定画面と一致する正しく翻訳されたラベルが表示されるようになりました。

詳細については、[リリースノート][Chimera Agent v0.49.1](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.49.1)を参照してください。更新するには、`chimera-desktop --update`を実行するか、公式サイトから最新バージョンをダウンロードしてください。
