## 多言語対応の更新ダイアログと手動更新チェック

Chimera Agentは、更新ダイアログを含め、あらゆる場所でユーザーの言語に対応するようになりました。以前は、アプリの言語設定に関係なく、更新ダイアログは英語のみでした。これが修正され、ダイアログはオペレーティングシステムの言語に従うようになりました。この変更により、アプリの言語設定を変更していないユーザーはシステムの言語でダイアログを表示し、カスタマイズしたユーザーは引き続き英語で表示されます。

さらに、トレイに**更新をチェック**オプションが追加されました。これは、手動で更新チェックを要求する初めての方法です。自動チェックは起動時に一度実行され、更新がない場合はユーザーに煩わされないように静かに動作します。しかし、この静けさは失敗と誤解される可能性があり、ユーザーが不必要にアプリを再起動する原因となることがありました。新しい手動チェックにより、ユーザーはアプリが最新であることを確認したり、チェックが失敗した場合にフィードバックを受け取ったりできるようになりました。

## 翻訳されたエラーダイアログと変更されない診断情報

更新ダイアログだけではなく、アプリの他の部分も翻訳されました。2つのバックエンドエラーダイアログとトレイの終了オプションも、複数の言語で利用できるようになりました。ただし、翻訳されるものとされないものには明確な区別があります：

> **何をすべきかを伝えるものは翻訳されます。バグレポートに入るものは翻訳されません。**

例えば、バックエンドがクラッシュした場合、エラーメッセージはユーザーの言語で表示されますが、パス、OSエラー、バックエンドのstderrは元の形式のままです。これにより、ユーザーはシステムエラーを検索して理解する際に混乱することなく対応できます。

## 変更されない点

この更新では、バージョン0.48.0から機能していた更新メカニズム自体は変更されていません。自動チェックは引き続き起動時に実行され、インストールプロセスはユーザーが開始する形のままです。アプリの実行中に定期的なチェックは行われません。

直感的ではない点が1つ残っています：**ダイアログを表示するバージョンは、すでにインストールされているバージョン**であり、提供されているバージョンではありません。つまり、バージョン0.49.0を提供するプロンプトは、現在実行中のバージョンによって描画されます。バージョン0.49.0以降、このプロンプトはユーザーの言語で表示されます。

詳細については、[Chimera Agent v0.49.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.49.0)を確認してください。
