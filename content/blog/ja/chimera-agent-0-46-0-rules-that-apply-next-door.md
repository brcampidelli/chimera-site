## ルールが届かない時

スキルストアを含む5つのJSONストアでは、これまで並行プロセスが互いのデータを上書きするサイレントデータ損失が発生していました。学習済みの実行結果が、次の実行で記憶から消去される可能性がありました。これら5つ全てが現在、設定不要でアトミックなロック・書き込みを実現。同様のパターンで、インポート時にクラッシュするガバナンス機能とチェックなしで動作していたDiscordボットも修正されました。

## インシデントレポートとしてのスキルカード

`skills/`ディレクトリに23のカードが追加され、うち13枚は本プロジェクトの不具合から作成されました。各カードはTrigger/Do/Avoid/Check/Risk形式で失敗モードを文書化（コードではなくデータ）。ワークフロー段階（`define・build・verify・review・ship`）ごとにグループ化され、トピックタグ付けされています。インポート方法:

```
chimera skills-import skills/verify-before-claiming
```

カードはサイドカーファイルにより9言語をサポートし、元のSHA-256ハッシュを保持。システムは陳腐化翻訳（変更済みテキストを翻訳と主張）と不完全翻訳（欠落セクション）を検出しますが、明確なラベル付けにより翻訳欠落を許容します。

## 実際に機能するゲート

3つのエージェント不具合が、テスト失敗なしに重要コンポーネントを損なっていました。根本原因：チェックが要求動作ではなく許可例外をリストしていなかったため、新規動作出現時にゲートが開放されたままに。現在は例外を明記 — チェック回避が明示的に許可されていないものは全て検査対象になります。

10言語にわたる16のドキュメント記載が修正され、うち5件は完全な誤り：ガバナンスモードに`ask`は含まれず、デスクトップレールにチャット送信先はなく、`CHIMERA_TAVILY_API_KEY`はコードベースに存在しません。2つの楽観的記載には、反証データが併記されました。

```
pip install -U chimera-agent
```

カード閲覧はchimeraagent.space/skills [Chimera Agent v0.46.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.46.0)、オプトイン性能トレードオフは`bench/skillcard/RESULTS.md`を参照。
