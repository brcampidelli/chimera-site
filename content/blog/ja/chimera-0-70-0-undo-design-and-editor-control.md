## ターミナルは二流クライアントではなくなる

このリリース以前、`chimera chat` と `chimera assist` はデスクトップよりも狭い安全策で動作していた。コンテキストは上限に達するまで増え続け、プランは実行前に表示されず、ターンの Undo はより単純な復元経路に依存していた。そのギャップは今回で解消された。

ターミナルセッションはデフォルトでデスクトップと同じポリシーでコンテキストを圧縮する。以前の動作が必要なら `--no-compact` で無効化できる。`/plan <task>` はまずプランを表示し、承認後にのみタスクを実行する。プランの承認はリスクのあるアクションを事前承認するものではない。`/undo N` は直近 N ターンで触れたファイルを一覧表示し、確認を求め、Code 画面と同じ永続ストアから復元する。対象ターン以降に編集したファイルはそのまま残る。単純な `/undo` は直前のターンを元に戻す。

デスクトップでは会話ヘッダーに巻き戻しタイムラインが追加された。各保存ポイントには時刻と触れたファイル数が表示される。ポイントを選択すると、復元されるファイルと、後から編集したためにスキップされるファイルが正確に表示される。復元自体も同じタイムラインからやり直せる。保存コピーのないターンは理由付きで無効表示される。プレビューも復元経路もデスクトップブリッジには公開されないため、ペアリングされたデバイスや外部クライアントから復元をトリガーすることはできない。

## Editor は git が見るものを反映する

ファイルツリーは以前は名前のリストだけだった。今回から、変更・追加・未追跡ファイルには文字、フォルダにはドットが付き、Changes カードと同じ git ステータスが使われる。ステータスは保存後とエージェントのターン終了時に更新される。Ctrl+P でファイル名を指定して開く。HTML ファイルには Code 画面と同じサンドボックスで Preview トグルが付き、未保存の編集も含まれる。未保存の変更があるタブを閉じると、編集を続けるか、保存せずに閉じるか、保存して閉じるかを尋ねる。

選択ベースのアクションでコードの助けを求める方法が変わる。行を選択して Ctrl/⌘+L を押すと、`@` メンションと同じ経路で Code 会話にコンテキスト項目として送信される。Ctrl/⌘+I は `propose_change` を追加し、サーバーが読み取り専用で 1 ファイルと行範囲を指定して実行する。提案はインライン差分として返り、Accept と Reject が付く。Accept すると Editor を通じて保存される。応答前に行が変更された場合、提案は消える。開いている間にディスク上で変更されたファイルは差分とともに保持され、Keep か Undo を選ぶまで読み取り専用のままとなる。

Code コンポーザーはファイル、フォルダ、デザイン、最近の会話に対する `@` メンションをサポートするようになった。最大 8,000 文字のファイルはインラインで添付され、サニタイズされ、データとしてフェンスされ、読み取りとして台帳に記録される。それより大きいファイルやフォルダはエージェントが読むためのパスで渡される。絶対パスと `..` はターン実行前に拒否される。プロジェクト外へのシンボリックリンクと Chimera 自身の `.env` は解決時に拒否される。共有リンクのゲストはデザインや会話をメンションできない。

## Chimera Design がエクスポート、キャンバス、ツールを追加

Chimera Design は PDF、PNG、PPTX へのエクスポートに対応した。PDF は Playwright の Chromium で印刷される静的ページで、アートボードごとに 1 ページ、JavaScript はオフ、`data:` 以外のリクエストは中止される。PNG はアートボードごとに 1 画像、または zip を生成する。PPTX は各要素をアートボードごとのスライド上のフレームに配置する。Chromium または python-pptx が不足している場合、エクスポートは拒否され、インストールすべきものが表示される。自動ダウンロードは行われない。

キャンバスは Code 画面の中央スロットに開き、左に会話、右にキャンバスが配置される。操作ルートを通じて可視状態で自動保存される。手動編集とエージェント編集は 1 つの Undo 履歴を共有する。デザインを要求するターンには「Open in Chimera Design」アクションが表示される。キャンバスの横では、ブリーフから提案、選択の絞り込み、監査、トークンの編集、デザインのトークン適合チェック、要素ごとのコメント、バージョンの復元、HTML へのエクスポートが可能。復元とエクスポートは事前に確認を求める。

`design` ツールはターンがビジュアルデザインを要求した場合にのみ提供される。決定的な検出器がポルトガル語、英語、スペイン語をカバーし、アクセントは折りたたまれ、単語全体が一致する。「design pattern」や「system design」などのコードの意味では発火しない。ツールはポスチャに従い、HTML をボットに送信せず、出力を信頼できないものとしてマークし、ゲストのターンには関与しない。`CHIMERA_TOOL_DENYLIST=design` で削除できる。

## 今すべきこと

0.70.0 にアップデートしてターミナルセッションを開き、リスクのあるタスクの前に `/plan` を実行し、その後 `/undo N` を実行する。Editor ではブロックを選択して Ctrl/⌘+I を押し、提案された変更を差分として確認する。デザイン作業では、ビジュアルデザインを要求するターンからキャンバスを開き、そこからエクスポートする。完全なリリースノート: [Chimera Agent v0.70.0](https://github.com/brcampidelli/chimera-agent/releases/tag/v0.70.0)
